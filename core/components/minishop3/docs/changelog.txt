# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.2.1-beta1] - 2026-01-20

### Fixed
- MySQL 8.0 compatibility: renamed `rank` field to `sort_order` in `ms3_model_fields` and `ms3_model_field_sections` tables
- MySQL 8.0 compatibility: added backtick escaping for `rank` field in `modContext` system table
- Email verification letters not being sent (missing `modMail` import)
- Placeholder format in email lexicons (`{name}` → `[[+name]]`)
- Missing `minishop3:cart` lexicon loading in snippets

### Changed
- Orders grid: status now uses relation fields instead of direct JOIN
- Orders grid: added `order_status` (badge), `status_color`, `status_name` (relation) fields
- Orders grid: `delivery_name` and `payment_name` fields now use `relation` type

## [1.2.0-beta1] - 2026-01-16

### Added
- Order validation for delivery required fields (from `validation_rules`)
- Customer data validation (email/phone) when creating from order
- Customer creation during order finalization from address data
- Duplicate customer handling during order finalization
- Validation error lexicons for order fields (ru/en)
- OrderFinalizeService for order finalization logic

### Changed
- "Create Order" button renamed to "Create Draft Order"
- Custom routes can now override system routes
- Modernized thumbnail generation API
- Improved product selection UI in order management
- Moved inline styles to centralized CSS file

### Fixed
- Automatic token renewal instead of error on expiration
- Delivery required fields validation during order finalization
- Customer creation flow in admin order management
- Gallery upload/delete 500 error (incorrect getObject/getIterator usage, rank → position field)

## [1.1.0-beta1] - 2026-01-11

### Added
- ProductCardUI module for adaptive cart buttons in product cards
- Cart state display: "Add to cart" button or quantity controls (+/-)
- Automatic UI update when cart changes via `ms3:cart:updated` event
- New lexicons: `ms3_cart_add`, `ms3_cart_in_cart`
- Migration for adding ProductCardUI.js to frontend assets
- Tab descriptions for Utilities page tabs explaining each section purpose
- CSS class `.tab-description` for consistent tab description styling

### Changed
- Product card template (`ms3_products_row.tpl`) with dual-state cart forms
- Product page template (`product.tpl`) with cart state awareness
- Base template with `icon-plus` and `icon-minus` SVG icons
- Renamed "Расширение объектов" tab to "Свои поля" (Custom Fields)
- Renamed "Управление свойствами товара" to "Поля товара (админка)"
- Renamed "Конфигурация полей моделей" to "Поля форм (админка)"
- Improved layout: dropdown and button on same row in "Свои поля" and "Поля таблиц" tabs
- Removed duplicate titles from tab content (already shown in tab headers)

### Fixed
- CSS isolation for Dialog and ConfirmDialog components (appendTo="self")
- Product options (color, size) saving in msProductOption table
- Duplicate Delivery/Payment filters on Orders page
- Field visibility saving in product properties management
- Migration errors on clean installation
- Default value error for `created_at` field

## [1.0.0-beta1] - 2026-01-05

First beta release of MiniShop3 for MODX 3.

### Added
- Modern admin interface with Vue 3 + PrimeVue components
- Service-based architecture with dependency injection
- Flexible field configuration system for products, orders, customers
- Grid configuration system with customizable columns and actions
- API router with FastRoute for REST endpoints
- Customer management with addresses and order history
- Order management with status workflow and notifications
- Delivery and payment methods configuration
- Product gallery with drag-and-drop upload
- Extra fields system for extending entities
- Import functionality for products
- Notification system for order events
- Full lexicon support (Russian, English)

### Changed
- Complete rewrite for MODX 3.0+ compatibility
- PHP 8.1+ required
- Namespace changed to MiniShop3
- Database tables prefixed with ms3_
- ExtJS panels integrated with Vue components

### Dependencies
- Requires VueTools package for Vue infrastructure
- Uses PdoTools for template rendering

## [1.0.0-alpha] - 2025

- Initial alpha releases for testing and development.
